# 💰 MAS Tracker
### Sistem Keuangan Pintar by Rizki Nur Amaludin

Aplikasi keuangan modern dengan dukungan multi-mata uang, AI prediksi, dan fitur PWA lengkap.

---

## ✨ Fitur Unggulan

- 🤖 **AI Prediksi** - Proyeksi keuangan akhir bulan
- 💱 **Multi-Currency** - Dukungan IDR, EGP, SAR, USD, BTC, dan custom currency
- 📊 **Analisis Cerdas** - Grafik dan statistik real-time
- 🎯 **Anggaran & Target** - Kelola budget dengan notifikasi
- 🌙 **Dual Mode** - Dark/Light mode dengan kontras tinggi
- 👻 **Ghost Mode** - Sembunyikan data sensitif
- 📱 **PWA Fullscreen** - Install seperti aplikasi native
- ⚡ **Offline Support** - Berfungsi tanpa internet
- 🔒 **Local Storage** - Data aman di device Anda
